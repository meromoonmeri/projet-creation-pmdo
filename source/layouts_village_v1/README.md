# Layouts village v1 — terrains nus (aucune structure, aucun objet)

Trois fonds de carte 1200×896 au style T00 (prairie jaune-vert, chemins sableux, falaises
brunes), strictement vides : ni maisons, ni tentes, ni arbres, ni barrières, ni fleurs, ni
personnages. Chaque layout porte une mare plate pure magenta (255, 0, 255) prête pour
l'eau générée.

- `layout_place_ronde.png` : chemin sud, grande placette ronde centrale, mare ronde au milieu.
- `layout_place_marche.png` : chemin sud sinueux, grande place rectangulaire à l'est, mare en haricot à l'ouest.
- `layout_carrefour.png` : carrefour sud avec rond-point, mare ronde au sud-est, chemin vers le nord.
- `layout_place_nord.png` : chemin sud-nord rectiligne, grande place au nord adossée aux falaises, mare ronde à l'est.
- `layout_deux_mares.png` : petite placette centrale, deux mares rondes (ouest + est) cerclées de sable.
- `layout_plaine_ouverte.png` : prairie totalement ouverte (sans falaises), chemin sinueux sud-nord + branche est, mare à l'ouest.
- `planche_layouts.png` : les trois premiers en vignettes.
- `planche_layouts_2.png` : les trois suivants en vignettes.

Références : `source/village_pokemon_v1/reference/t00p02_t00.png` et décor VIL1 (textures).
Générés en un essai chacun. Ces layouts servent de base à de futurs villages bâtis (VIL3…) :
le bâti se générera par-dessus, le témoin = le layout lui-même.
