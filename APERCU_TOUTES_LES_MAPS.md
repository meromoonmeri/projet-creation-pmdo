## Régénérer la galerie

```sh
GH_TOKEN=$(gh auth token) python3 galerie/collect.py   # télécharge les aperçus + miniatures
python3 galerie/build_html.py                            # reconstruit index.html
python3 galerie/serve.py --port 8000                     # sert la galerie
```

Les images (`galerie/img/`) sont ignorées par git : elles restent dans le dépôt source, conformément à la convention du dépôt. Seuls les scripts, `data.json` et `index.html` sont versionnés.
