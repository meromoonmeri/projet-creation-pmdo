# New Era — Quest PMDO 0.8.12

Édition intégrale sans Git LFS prête à l'emploi pour **PMDO 0.8.12** (`3639` cartes `.rsground`, `2567` feuilles `.tile`, `219` décors `.dir`).

## Installation

1. Installez **PMDO 0.8.12** ou plus récent.
2. Copiez les dossiers `town02`, `town02_tiles_pack_a`, `town02_tiles_pack_b`, `town02_tiles_pack_c` et `town02_tiles_pack_d` dans `PMDO/MODS/` (ou exécutez `fusionner_en_un_seul_dossier.py` pour tout regrouper dans `town02/`).
3. Sélectionnez la quête **New Era** dans le menu Quêtes de PMDO.
